# jack-3d-creator

Personal portfolio website built with React, Vite, TypeScript, and Tailwind CSS.

## Sections

- Hero
- Marquee
- About
- Services
- Projects
- Contact

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
